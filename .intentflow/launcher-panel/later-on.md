# 后续想法备忘（launcher-panel）

> 设计阶段识别但此时不做的事项，以及未来演进方向。只记录想法，不做设计预留。

### 想法列表

- **L01**：面板高亮更新从「增量 postMessage」升级为「状态驱动重渲染」
  - 现状：面板仅 6 个按钮 + 一个高亮态，增量消息（highlight）足够简单，不做抽象。
  - 何时做：面板按钮增多、出现二级菜单或多选状态时。
  - 备注：届时把 panel.js 的状态渲染抽成「state → html」纯函数即可。

- **L02**：内容区单区 panel 支持多区同屏组合
  - 现状：每个内容区独立单 panel（ViewColumn.One），点哪个开哪个，互不联动；上下分栏编排已随 focus 模式删除。
  - 何时做：用户想「会话列表 + 输入区」并排看时。
  - 备注：只需在 focus.openArea 之上加一个「指定 ViewColumn + 分栏」的组合入口，当前接口无需预留。

- **L03**：面板加「停止 DSH」按钮
  - 现状：用户明确不需要，stop 走现有状态栏按钮/命令。
  - 何时做：用户觉得面板该能一键停服务时。
  - 备注：加一个 `{type:'stop'}` 消息 + panel 一个按钮即可，不涉及结构调整。

- **L04**：打开方式增加「默认封装不显示地址栏」与 Simple Browser 的视觉区分说明
  - 现状：三个打开方式按钮用文字区分，未加图标/tooltip。
  - 何时做：用户反馈按钮含义不清时。
  - 备注：纯面板 HTML 调整，不涉及扩展逻辑。

### 与当前设计的关系（轻量提示）

- L02 可能扩展 focus.openArea 的接口，但当前无需提前预留，届时直接加方法即可。
- L03 只影响 panel.js 的消息协议，当前保持两消息类型即可，届时追加一条。
- L01/L04 纯面板前端，不影响扩展侧任何接口。
